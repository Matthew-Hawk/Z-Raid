# Encounter illustration prompts

Generated with the built-in imagegen tool. Each location's prompt below was appended to the shared prompt. Files live in `assets/encounters-pharmacy.png`, `assets/encounters-metro.png` and `assets/encounters-checkpoint.png`. Ten scenes per atlas, ordered left to right, then top to bottom, correspond to the two storylines' five moments. SVG viewports select a scene without modifying the generated pixels.

## Shared prompt

Create ONE environment scene atlas for Z-RAID. EXACTLY ten LANDSCAPE panels in a STRICT 2-column by 5-row grid, edge-to-edge cells of equal size, no borders or gutters. Each cell is a complete separate scene; no objects cross boundaries. Overall portrait canvas 4:5, each panel landscape 8:5. Stylized polished 16-bit-inspired fine pixel illustration matching the game's recent location dioramas: rich worn materials, navy shadows, teal rim light, muted amber and green accents, strong readable narrative props. Camera at human eye level, atmospheric cinematic composition, suitable as subtle background behind white encounter text. Dark left areas, main focal prop toward center/right. No words, lettering, numbers, captions, UI, logos, watermark. Depict only the situation before a decision, no victorious outcome, no identifiable player character. Non-graphic zombie silhouettes allowed. Read cells row-major left to right, top to bottom.
